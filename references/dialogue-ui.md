# 多风格对话界面

风格注册于 `scripts/themes.py`，通过 `scripts/render.py` 合成进视频。两套皮肤继承 `scripts/dialogue_ui.py` 的字体测量、换行、真实词时间戳与固定基线绘制。不要重新生成一张包含台词、角色名或词汇的整屏图片；动态内容必须可排版，并随真实词时间戳变化。

## 风格选择

`ui_theme` 支持 `auto`、`jade-paper`、`mystery`。省略即为 `auto`：IP 中的柯南、福尔摩斯、侦探、推理、悬疑，以及 Conan、Case Closed、Sherlock、Detective、Mystery 关键词会选择悬疑；其余保持青玉宣纸，兼容既有输入。用户明确要求的风格优先，由 AI 设置具体字段。未知值在配音前报错，不静默换成别的界面。

例如：

```json
{"ip": "名侦探柯南", "ui_theme": "mystery", "scene_label": "米花美术馆 · 午夜"}
```

这是内部剧本的字段示例，不是交付给用户的额外文件。修改主题后运行完整构建以更新缓存时间轴；未改动的语音继续复用。

## 青玉宣纸（jade-paper）

装饰与对白框由 `scripts/jade_paper.py` 绘制。

- 暖宣纸底、细旧金双边框、少量云纹和浅山影；青玉名牌嵌入左侧，中文名在上、英文名在下。
- 英文使用随附 DejaVu Serif，标题与名牌使用 Noto Serif CJK 简体中文字形；中文译文使用 Noto Sans CJK。字体及许可证随仓库分发，不依赖系统恰好装有某款字体。
- 台词用深墨色；当前发音词使用浅青玉笔触底与深青文字。下划线匹配完整词组，不标记其他位置恰好出现的同一个单词。
- 同一行英文共用固定基线，按字体大写高度定位并使用 Pillow `ls` 基线锚点。不能对每个单词使用 `lt` 字形顶部锚点，否则大小写和 g/p/y 等字母会造成底线错位。高亮切换只改变底色与字色，文字坐标、字号和基线始终不变。
- 生词解释留在同一卷轴右侧，以细金线分隔，包含词组、IPA、语境义和用法。无生词时对白扩展到右侧。
- 左上为中文标题、小印章及 `scene_label`；右上只保留难度与语言。底部用细金线与菱形标记表示播放进度。
- 视频中的理解检查使用相同的纸色、青玉色和金线；仍为倒计时自动揭晓，不增加网页或真正可点击按钮。

## 悬疑案卷（mystery）

由 `scripts/mystery.py` 绘制独立的界面，不给玉牌或云纹简单换色：

- 底部使用深色案卷板、细灰蓝边线、红色身份栏，人物中英文名横向排列。没有宣纸纹理、玉牌或流苏。
- 英文使用 DejaVu Sans，浅色文字配琥珀色高亮底；词组下划线同为琥珀色。人物与背景之间不出现仙侠光点。
- 右侧 `LANGUAGE FILE` 显示词组、音标、中文义和用法。无词汇时去掉该栏分隔线，正文扩展至右侧。
- 片头是案件标题页，选择题是推理判断页，片尾是证据式词汇复习。中间区域保留给人物与线索，不提前标记凶手。
- 深色纹理固定种子并缓存；高亮不改变字体位置、字号或基线。

## 排版与边界

逻辑画布为 1280×720，最终按输出分辨率缩放。青玉卷轴范围约为 `(32,497)–(1248,677)`，悬疑面板约为 `(28,480)–(1252,682)`，将上方约三分之二留给场景。

| 元素 | 规则（逻辑像素） |
|---|---|
| 英文正文 | 青玉 x=220、字号 34 至 24；悬疑 x=56、字号 32 至 24；有词汇时右边界 912，否则 1212；按词换行 |
| 中文译文 | 正文下方独立区域；字号 19 至 16，最多两行，底部不超过 y=666 |
| 玉牌 | 中英文名分别排版，最多各两行；中文字号下限 17，英文下限 11 |
| 词笺 | x=968，宽 253；词组最多两行，字号下限 19；IPA、释义和提示总高度受限 |
| 理解检查 | 两个选项；英文最多两行，中文最多一行，超限直接报错 |

纸纹、玉纹及静态装饰使用固定种子并缓存，不随帧重新随机生成。高亮只出现在真实 WordBoundary 的开始到结束之间，不在停顿中伪造朗读。文字超出边界会在编码前报错；缩短解释或拆分对白后重新构建，不截字、不遮挡、不无限缩小字体。

## 内部检查

用代表帧检查短句、长句、多词表达、旁白、长角色名、双语与纯英文画面、人物入退场、选择题等待和揭晓。测试覆盖 640、1280、1920 三种宽度，并将两套主题的逐词绘制与整行原生排版比较，检查高亮前、中、后的字形位置。还需检查自动选主题、显式覆盖、未知主题报错及儿童身高。查看帧仅供内部诊断，放在临时目录，检查后清理。

## 增加第三种风格

新增独立皮肤类，继承 `DialogueUI` 的测量和 `draw_words`，实现静态底板、`draw`、`draw_highlight` 与 `choice`。需要独立片头、片尾时实现 `title` / `outro`，否则使用渲染器的通用页。通过类属性设置 `FONT_KIND`、`LEFT`、`TOP`、字号上限与文本配色，不复制一套逐词定位代码。然后在 `THEMES` 注册稳定名称，更新选择规则、数据契约及跨主题测试。新增皮肤不需要视频模型或带文字的图片素材。

界面更新不改变制作与交付规则：禁止视频生成服务，最终制作任务只交付一个 `episode.mp4`。
